# Design

## Product feel

A lab, not an LMS.

Desktop defaults to a split view:

- visual manipulation on the left;
- prompt/explanation/action on the right.

On smaller screens, the visual stacks above the lesson.

## Interaction rules

- One primary action per conceptual beat.
- Show state changes immediately after learner input.
- Keep explanatory copy short enough that manipulation remains the main activity.
- Use the football pitch as a causal visualisation, not a decorative background.
- Avoid celebratory gamification that implies a wrong prediction is a learning failure.

## Motion

Allowed when it clarifies:
- model state before/after training;
- probability or boundary changes;
- new feature entering the representation;
- score changes after a learner action.

Avoid ambient decorative animation in V0.
